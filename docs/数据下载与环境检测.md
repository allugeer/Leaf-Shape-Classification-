## 操作步骤（供复现）

1. 安装 Python 3.11.9，并勾选 Add python.exe to PATH。
2. 在 VS Code 中打开项目文件夹，新建终端。
3. 运行 `python -m venv .venv` 建立虚拟环境。
4. 运行 `.venv\Scripts\Activate.ps1` 激活环境。
5. 运行 `python -m pip install torch torchvision pillow` 安装依赖。
6. 把测试图片放入 `data/samples/` 文件夹。
7. 运行 `python check_images.py` 即可检查图片能否被正常读取。
